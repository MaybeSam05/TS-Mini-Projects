A bunch of TypeScript mini-projects to teach me TypeScript.

Work through these in order. Each folder contains:

- `README.md` with the assignment, requirements, and test cases
- `solution.ts` as your blank file to code in

## Terminal Workflow

1. Run `npm install` once.
2. Run `npm run list` to see all projects.
3. Run `npm run run -- indoor-voice` to execute a project's `solution.ts`.
4. Run `npm run check -- indoor-voice` to type-check one project.
5. Run `npm run check:all` to type-check every project.

Note: since each `solution.ts` starts empty, `npm run run` becomes useful after you add code and optionally some `console.log` calls for manual testing.
